## Доступ і майбутня публікація

**Репозиторій публічний за D-185.** Поточний README, код, документація
й зображення відкриваються без GitHub-акаунта. До явного доручення про
публікацію 2026-11-02 репозиторій був PRIVATE; попередні записи аудиту
та релізів описують стан на час своїх перевірок.

Поточний звіт використовує стандартне вікно браузера: **`demo` / `unicorn-demo`**.
Це погоджена публічна пара для читання синтетичної статистики. Квіз і
захищений звіт лишаються на чинному URL, без нових ресурсів чи функцій.
[Інструкція перевіряючому](../README.md#подивитися-демо),
[технічні межі D-183](decisions.md#d-183--публічний-доступ-до-звіту-чинного-демо).
Партнерський токен, HMAC, Cloudflare та GitHub credentials не публікуються;
ignored `.wrangler/demo-secrets.json` не передають перевіряючому.

Порядок для перевіряючого:

1. Відкрити [репозиторій](https://github.com/deysan/unicorn-funnel-analytics)
   і почати з README: доступи, скріншот, демо, схема й маршрут документації.
2. Переглянути звіт за 1 листопада з опублікованою парою або пройти квіз
   і перевірити власний приріст за поточний UTC-день.
3. Для читання репозиторію запрошення collaborator не потрібне.

Історію збережено за D-184. GitHub-публікація не змінює Basic Auth демо.
Запрошень і повідомлень перевіряючому не надсилали.

## Публікація GitHub 2026-11-02

Виконано після явного доручення D-185. GitHub CLI підтвердив PUBLIC,
`isPrivate=false`; незалежний запит без Authorization/Cookie до GitHub API
повернув HTTP 200, `private=false`, `visibility=public`.
Анонімна HTTP-перевірка о 2026-11-02T10:01:26.971041+00:00 виконала **25 запитів — усі 200**:
сторінка репозиторію, GitHub-сторінки README/дизайну/демо/зображень,
16 унікальних файлових цілей README через raw (включно з PNG, SVG та
редагованим Excalidraw), commit і обидва CI run. Використано нові HTTP-запити
без токена, Authorization, Cookie, cookie jar або netrc. PNG повернув
`image/png`, SVG — `image/svg+xml`; файли не потребують GitHub-входу.
Локальні посилання та якорі також перевірені на цілісність.

Демо перевірене лише GET: health 200; звіт без доступу — 401,
з `demo` / `unicorn-demo` HTML/status/funnel — 200; `no-store`, без Set-Cookie.
Режим normal, Cron complete/stale=false, pending/in-flight=0, без пауз і
помилок, історія confirmed від 2026-11-01. GitHub-сесія для звіту не потрібна.
Квіз та локальні dev-адреси під час цієї перевірки не відкривалися.

Код і deploy `2ba32c3` не змінювалися; повні тести через ці документаційні
правки не повторювалися. Публікацію й результати оформлено звичайним
документаційним комітом; попередні SHA/історичні докази збережені.
