Перевірено 88 Markdown-документів: 712 локальних посилань, включно з
якорями, ведуть до наявних цілей. Для 121 унікальної зовнішньої HTTP-адреси

## Доступ і майбутня публікація

GitHub перевірено 2026-11-02 через автентифікований `gh repo view`:
`deysan/unicorn-funnel-analytics`, `visibility=PRIVATE`, `isPrivate=true`,
default branch `master`. GitHub-конектор не мав доступу (404), тому цей
висновок ґрунтується на GitHub CLI, а не на публічній недоступності сторінки.

Поточний звіт використовує стандартне вікно браузера: **`demo` / `unicorn-demo`**.
Це погоджена публічна пара для читання синтетичної статистики. Квіз і
захищений звіт лишаються на чинному URL, без нових ресурсів чи функцій.
[Інструкція перевіряючому](../README.md#подивитися-демо),
[технічні межі D-183](decisions.md#d-183--публічний-доступ-до-звіту-чинного-демо).
Партнерський токен, HMAC, Cloudflare та GitHub credentials не публікуються;
ignored `.wrangler/demo-secrets.json` не передають перевіряючому.

Порядок наступного етапу:

1. Перевіряючий відкриває демо, проходить квіз і дивиться статистику
   з опублікованою парою. Доступ до GitHub для цього не потрібний.
2. Зберегти цей репозиторій і його історію за **D-184**. Власник явно
   прийняв старі формулювання й посилання у попередніх комітах;
   актуальну версію очищено, rewrite/squash не потрібні.
3. Лише за наступним явним дорученням зробити repo public через
   Settings → Danger Zone → Change visibility. Зараз лишити PRIVATE.
4. Після відкриття перевірити README, картинки, посилання й звіт без
   GitHub-сесії та передати перевіряючому URL репозиторію.

Публічний GitHub відкриває код та історію Actions/logs; сам по собі він не
змінює Basic Auth демо. [GitHub: зміна видимості](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/managing-repository-settings/setting-repository-visibility),
перевірено 2026-11-02. До відкриття можна запросити GitHub-акаунт через
Settings → Collaborators → Add people, але особистий private repo дає
collaborator **write**, не окремий read-only: [GitHub: рівні доступу](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/repository-access-and-collaboration/permission-levels-for-a-personal-account-repository),
перевірено 2026-11-02. Запрошення й повідомлення в цій роботі не надсилалися.
