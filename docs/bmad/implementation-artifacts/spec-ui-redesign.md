## Intent

Власник 2026-11-06 схвалив локальний варіант «після» та явно доручив
перенести його дизайн до реального квізу й звіту Unicorn. Референс палітри —
https://unicorn.pro/: блакитний #1ab8e4, ціановий #06eef8, темний #090909,
світлі #f5f4f3/#f9f9f9; кольори витягнуто з HTML/CSS 2026-11-06.
Погоджені компонування: спільна темна шапка, desktop-квіз із боковим
поясненням і кроками, ширший звіт із компактними фільтрами, таблицями,
показниками й окремим переглядом технічного стану; мобільна адаптація.

Переносимо оформлення поверх чинних контролерів, API та реальних DTO.
Імітації контролерів, фіксовані результати й тестові числа локального макета
не входять у застосунок. Бізнес-правила, події, повтори, recovery, часові
межі, формули конверсій, URL-фільтри, авторизація й polling незмінні.
Усі наявні технічні факти й невідомі стани залишаються доступними.
Діагностика /diagnostics зберігається. Без нових залежностей, ресурсів,
міграцій, зовнішніх переходів, push або deploy.

## Implementation Notes

- Дослідження: `App.tsx` викликає `controller.rendered` лише після DOM,
  блокує форми до ACK і на busy; ці effects та умови зберігаємо.
- `Report.tsx` зберігає draft/applied, історичні ID, глобальні помилки та
  точні пари Conversion. Контролер не монтуємо заново при зміні розділу;
  навігація розділів локальна, не додає query-параметрів до строгого API.
- Зміни: `src/client/Brand.tsx`, `App.tsx`, `Report.tsx`, `style.css`;
  smoke-перевірки нової навігації й адаптивності та документація D-186.
- Відкритих продуктових питань і незворотних дій немає. Обсяг обмежено
  шаром представлення; поточний checkout master чистий, baseline
  `bb8f0fd64298e98e1fb080f740785cddfa967529`.
- Перевірки: typecheck, Vitest, build, повна наявна браузерна матриця;
  додатково перемикання розділів зі збереженням draft, помилки поза
  панелями, нульовий знаменник без meter, mobile/desktop screenshots.

- Реалізовано спільний `Brand`, оформлення всіх станів квізу, дві
  локальні панелі звіту. Контролери, сервер, DTO та залежності не змінені.
  Глобальна помилка технічного стану й попередження про проблеми
  залишаються видимими на огляді. Навігація не змінює query string.
- Додано три регресійні сценарії: навігація/draft/відсутність зайвих
  запитів (у п’яти браузерних проєктах), помилки між панелями та meter
  при нульовому знаменнику. Чинний тест технічних подробиць лише
  відкриває нову панель; його перевірки фактів не послаблено.
- Незалежний blind-review в окремому контексті завершився без
  підтверджених findings. Квоту проблем відкинуто згідно з AGENTS.md.
  Гіпотезу overflow довгих назв перевірено Chromium на 320–1280 px і
  відхилено. Спроба micro-check Firefox рев’юера не запустила профіль;
  вона не вважається перевіркою Firefox або заміною повної матриці.
- Браузерний тест виявив, що текст декоративної галочки потрапляв у
  label вибраного варіанта; точний пошук поля після повернення до кроку
  переставав збігатися. Галочку перенесено в CSS `::after` порожнього
  `aria-hidden` span. Нативні `checked`, labels і чинні тести збережено.
  Окремий reviewer перевірив вузьке виправлення без нових зауважень.
- Через повільне читання залежностей у workspace перший повний запуск
  отримав 610/611: timeout імпорту в незміненому `demo-smoke.test.ts`.
  Повторна перевірка виконана в тимчасовій локальній копії з тим
  самим lockfile, Node 24.22.2 / npm 11.19.1; 116 файлів коду, тестів,
  міграцій і конфігурацій звірено побайтово. Залежності встановлено
  offline з кешу; таймаути й тести не послаблено. Попередні перервані
  спроби не зараховуються як успішні.
- Фінальний `CI=true npm run check` — exit 0: typecheck, **611 Vitest**,
  build, **96 Playwright** (групи 26 + 24 + 6 + 9 + 4 + 2 + 17 + 8).
  Chrome, Firefox, WebKit, mobile Chromium і mobile WebKit пройдені.
  Знімки реального квізу й звіту в desktop/mobile візуально перевірено;
  знімок звіту використовує синтетичну API-фікстуру браузерного тесту.
- Документацію звірено з ТЗ, D-186 та фактичним diff; 277 локальних
  цілей посилань існують, `git diff --check` — без помилок.
  Контролери, сервер, shared DTO та package/lockfile не мають diff.
- Відкладених findings немає. Хмарних дій, deploy або зміни ресурсів немає.
