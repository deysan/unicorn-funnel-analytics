Фікстури синтетичні. Snapshot quiz включає users, Lead, events/delivery,
clicks, request_results, capacity/system control і transaction assertions.
Постбек має окремий snapshot із partner_events. Чинні секрети середовища
не додані до тестових даних або документації; реальних зовнішніх дій немає.

Перший запуск виявив помилку часової фікстури expired: last_active_at був
раніше created_at, SQL CHECK її відхилив. Обидві часові позначки перенесено
в минуле; обмеження схеми не послаблено. Підсумкові перевірки — у
[стані M3](m3-recovery.md).
